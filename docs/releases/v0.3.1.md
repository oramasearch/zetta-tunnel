# zetta-tunnel v0.3.1

**Released 2026-11-16.** A patch release: the `corosio` submodule is fetched over HTTPS, so a
recursive clone needs no GitHub key. The binary and image are otherwise those of
[v0.3.0](v0.3.0.md).

## What it includes

| Change | Pull request |
|---|---|
| **`modules/corosio` is fetched over HTTPS.** With the SSH URL, `git clone --recurse-submodules` failed for anyone without a GitHub key, here and in every repository that pins zetta-tunnel. The pinned commit is unchanged | #60 |
| The v0.3.0 image digest recorded in its notes | #59 |

## What it does not include

Everything [v0.3.0](v0.3.0.md) lists as not included, and #48 (isolation and per-workload limits for
the mesh), which is deferred.

## Known issues

The known issues of [v0.3.0](v0.3.0.md) still apply.
